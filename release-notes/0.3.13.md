# 0.3.13 (20) — development preview

Public APK release: pending. These notes describe the current test build, not a
stable release announcement.

- Updated German and English privacy information, with a public privacy/deletion link.
- A copyable report identifier helps with data deletion requests.
- Android Auto asks you to accept updated notices on the phone before continuing.
- EV launcher icon supports standard, adaptive and monochrome launcher treatments.
- Previous startup crash fix retained.

Compatibility: Android 8.0+ (API 26), 64-bit ARM. Android Auto access is managed
separately through Google Play testing. Availability depends on the phone and host.

Known boundaries: battery estimates use manually entered vehicle/charge data;
downloaded maps do not provide offline route calculation; charger status/prices
and speed limits are not guaranteed. Real-world driving validation remains ongoing.
